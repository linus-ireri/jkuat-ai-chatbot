VeritasRAG Sample Knowledge Document (DEMO)
============================================

This file is labelled demonstration content for Generic RAG testing.

Product overview
----------------
VeritasRAG provides two modes: Generic RAG for private document workspaces,
and JKUAT RAG for university knowledge with role-aware dashboards.

Generic RAG ingestion lifecycle
-------------------------------
Uploaded → Extracting → Chunking → Embedding → Indexing → Ready

Evidence rules
--------------
Answers must be grounded in retrieved excerpts. If this document does not
contain the answer, the assistant should abstain rather than invent facts.
